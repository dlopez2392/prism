# Consumer personal-finance app — market and integration research

**Date:** 2026-09-27 · **For:** Prism (`apps/finance`) · **Status:** web-verified;
items that could not be confirmed from a primary source are marked **[unverified]**.

## 1. Bottom line

1. **The category leader sets the bar, and the bar is visual.** Monarch's cash-flow
   Sankey is described by reviewers as its "most screenshotted screen"; Copilot wins
   Apple Editor's Choice on design alone. A new entrant competes on *how money looks*
   first, and features second.
2. **The biggest functional gap is the future.** YNAB and Copilot have no forecasting
   (Copilot's is an open feature request); Simplifi's projected cash flow is the only
   mainstream answer. A day-by-day balance forecast with "safe to spend" is the
   clearest differentiator available.
3. **AI is now table stakes, trust is not.** ChatGPT (May 2026) and Perplexity
   (April 2026) both launched Plaid-powered personal finance; Rocket Money shipped an
   Anthropic-built agent (Aug 2026). Yet only ~3% of Americans trust AI financial
   advice "a great deal". The winning posture is **AI that shows its work** —
   every claim cites the transactions behind it.
4. **Start on Plaid; architect for a second aggregator.** Monarch and Copilot both run
   multiple aggregators with fallback. Bank data-access fees (JPMorgan since 2025) and
   an unsettled Section 1033 rule mean aggregator costs will rise — design for fewer,
   webhook-driven pulls.

## 3. Bank connectivity (US)

| Provider | Model | Developer experience | Notes |
|---|---|---|---|
| **Plaid** | Self-serve pay-as-you-go, Growth, Custom; per-unit prices not public | Best: free sandbox, "Limited Production" (200 live calls/product), MCP servers | 12,000+ institutions, ~70% share. **Prism's primary.** |
| **MX** | Enterprise (~$15k–90k/yr per Vendr) | Free sandbox (100 users, top 15 banks) | Strong cleansing; data-mixing incident 2026-05-28 |
| **Finicity** (Mastercard) | Test drive / PAYG / custom; unpublished | OAuth testing needs an account manager | Good fallback candidate |
| **Teller** | ~$0.30/enrollment/mo transactions [unverified] | Free sandbox + 100 live dev connections | Direct connections to big banks, ~7,000 institutions |
| **Akoya** | Bank-owned network | Heavy onboarding | Use via an aggregator, not directly |
| **Stripe Financial Connections** | Public: $1.50/verification, $0.30/acct/mo transactions | Excellent | Only 180 days of transactions |
| **Yodlee** | ~$6k–60k+/yr | Free sandbox | Sold to STG, Sep 2025 |

**Regulation — Section 1033 (open banking):** finalised Oct 2024; CFPB opened
reconsideration Aug 22, 2025; a federal court (E.D. Ky.) enjoined enforcement in late
Oct 2025; a new proposal went to OIRA in Aug 2026 and is **not yet published** —
reportedly allowing banks to charge after a free quota. New York bills A10640/S9483
would ban such fees (in committee).
[ABA](https://bankingjournal.aba.com/2025/11/kentucky-federal-court-enjoins-cfpb-from-enforcing-current-1033-final-rule/) ·
[Consumer Finance Monitor](https://www.consumerfinancemonitor.com/2026/08/06/cfpb-sends-new-section-1033-open-banking-proposal-to-oira-for-review/)

**Data-access fees:** JPMorgan began charging aggregators in July 2025 and signed paid
deals with Plaid (Sep 2025), Yodlee (Nov 2025), Morningstar and Akoya; Wells Fargo and
PNC are pressing for similar terms; Fidelity and Schwab also charge. Plaid is not
passing the cost on *for now*.
[CNBC](https://www.cnbc.com/2025/11/14/jpmorgan-chase-fintech-fees.html) ·
[Payments Dive](https://www.paymentsdive.com/news/plaid-to-pay-for-jpmorgan-data-open-banking-fintechs/760192/)

**Implication for Prism:** `/transactions/sync` with a stored cursor and
`SYNC_UPDATES_AVAILABLE` webhooks, never polling; pricing headroom in the
subscription; the provider-neutral domain model already in `src/lib/finance/types.ts`.

## 4. Integrations beyond the bank — what has a real API

| Integration | Realistic path | Verdict |
|---|---|---|
| Investments | Plaid Investments; SnapTrade (Robinhood, Fidelity read-only) | **Ship** — Plaid part is live in Prism |
| Crypto | Coinbase OAuth2 `wallet:accounts:read`; public wallet addresses | **Ship next** |
| Credit score | Experian Connect, SavvyMoney, bureau resellers (FCRA work). **Credit Karma has no third-party data API** (it does run an MCP connector inside Claude) | **Partner** |
| Home value | Zillow's public API retired 2021; Bridge is MLS-only. ATTOM (~$299/mo+) or Estated | **Partner** |
| Vehicle value | VinAudit (Monarch uses it) | **Ship later** |
| Venmo / PayPal / Cash App | No public consumer-data APIs; appear via linked bank | **Limited** — email-receipt parsing needs Google's restricted-scope review |
| Apple Card/Cash/Savings | FinanceKit — iOS/US only, Apple entitlement; background delivery in iOS 26 | **Native app only** |
| Payroll / income | Plaid Income, Argyle, Pinwheel (B2B, per pull) | **Partner** — powers payday-aware forecasts |
| Calendar reminders | Google Calendar API or ICS feed | **Easy win** |
| AI assistants | Own MCP server (read-only), cite transactions | **Differentiator** |

| 1. Copilot-grade design on **every** platform | Responsive web app, mobile-first, dark + light, vibrant validated palette | ✅ |

| 5. Connections that stay up | Health per institution on Connections; fallback aggregator | ✅ health · fallback roadmap |

## 6. Recommendation

Build Prism as **the visual, forward-looking money app that shows its work**:
Sankey + net worth + spending pace (parity), forecast + safe-to-spend (lead),
evidence-backed insights (trust). Launch on Plaid alone, add a fallback aggregator
before scaling paid acquisition, and treat household mode and the MCP server as the
next two headline features.
